每当开始一件新事情, 我总喜欢先写一篇「你好, 世界」。这一次的主角, 是这个博客本身。

## 为什么还要写博客

社交平台的信息流越来越快, 快到文字还没有沉下去就被冲走了。我希望有一个慢一点的地方:

- 文章是我自己的, 不会被算法重新排序；
- 页面永远在线, 十年后回来还能找到今天的想法；
- 排版由我决定, 读起来舒服是第一原则。

于是就有了这里。

## 这个博客是怎么搭起来的

简单说几句技术选型, 细节会在后面的文章里展开:

1. **前台**用 Astro 做静态生成, 构建出纯 HTML, 访问速度快、对国内网络友好；
2. **交互部分**(点赞、评论、登录) 用 Vue 组件按需加载, 页面其余部分保持零 JS；
3. **后台 API** 用 Hono + PostgreSQL, 草稿保存在数据库里, 发布后同步为 Git 仓库中的 Markdown。

> 把内容放在自己的数据库和 Git 仓库里, 是我能想到的最安心的写作方式。

## 接下来会写什么

技术笔记、读书摘录、还有偶尔的生活随想。没有更新频率的承诺, 只有一条原则: 每一篇都值得你点开。

欢迎常来。
